Cara tambah minisite baru

Dua jalur. Pilih sesuai mood dan sinyal.

Jalur cepat: satu perintah

  1. Buka terminal di folder portofolio ini.
  2. Jalankan node add-minisite.mjs https://nama-situs.pages.dev
  3. Skrip akan mengambil judul dan deskripsi situs, lalu menulisnya ke projects.json.
  4. Rapikan teks deskripsinya kalau perlu, lalu git add . && git commit -m "tambah minisite" && git push

Jalur santai: edit lewat browser

  1. Buka repo portofolio di GitHub, klik projects.json, lalu ikon pensil.
  2. Salin satu blok { ... } yang sudah ada, tempel di bawahnya, jangan lupa koma.
  3. Ganti name, url, desc, tags, added.
  4. Klik Commit changes. Cloudflare Pages otomatis menayangkan ulang dalam sekitar satu menit.
